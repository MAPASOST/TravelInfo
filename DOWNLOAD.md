# Download Your App

## Where to Download

The app is automatically built and ready to download!

### Direct Download Link:

Go to: **https://github.com/MAPASOST/TravelInfo/actions**

1. Click on the most recent workflow run (top of the list)
2. Scroll down to "Artifacts" section
3. Click on **"BudgetVisualization-Windows"**
4. This downloads a ZIP file
5. **Unzip the file** - inside you'll find `BudgetVisualization.exe`
6. **Double-click the .exe to run!**

## That's It!

- No installation needed
- No coding required
- Just download, unzip, and double-click!

## What You Get

- **BudgetVisualization.exe** (~150-200 MB)
- Portable - run it from anywhere
- Upload your Excel budget files
- Generate charts and PDF reports
- All features included

## Troubleshooting

**If you get a Windows security warning:**
- Click "More info"
- Click "Run anyway"
- This is normal for unsigned apps

**If the download doesn't work:**
- Make sure you're logged into GitHub
- The build takes 5-10 minutes after code is pushed
- Check back in a few minutes if artifacts aren't ready yet
