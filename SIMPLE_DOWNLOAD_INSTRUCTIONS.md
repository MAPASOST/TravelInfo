# ✈️ Flight Price Tracker - Simple Download Version

**No installation needed! Just download and open in your browser.**

## 📥 How to Download and Use

### Step 1: Download the App
1. Go to your GitHub repository: https://github.com/MAPASOST/TravelInfo
2. Click on the file: **`FlightPriceTracker.html`**
3. Click the **"Raw"** button (top right)
4. Right-click anywhere on the page → **"Save As"**
5. Save it to your computer (Desktop or Documents folder)

### Step 2: Open the App
1. Find the **`FlightPriceTracker.html`** file you just downloaded
2. **Double-click** it
3. It will open in your default web browser (Chrome, Firefox, Edge, Safari)

**That's it! The app is now running!** 🎉

---

## ✨ How to Use the App

### Add a Destination
1. Enter **Origin Airport** code (e.g., JFK, LAX, ORD)
2. Enter **Destination Airport** code (e.g., LHR, CDG, NRT)
3. Click **"Add Destination"**

### Track Prices
1. Click **"Add Price"** on any destination card
2. Enter the price you found (e.g., 299.99)
3. Enter the flight date
4. (Optional) Enter airline name
5. Click OK

### View Predictions
- After adding **3 or more prices**, predictions automatically appear!
- Shows expected price 30 days ahead
- Displays confidence level and trend

### Set Price Alerts
1. Click **"Set Alert"** on any destination
2. Enter your target price
3. You'll get a browser notification when new prices are below your target!

### View Details
- Click **"Details"** to see your complete price history
- View all past prices and dates
- See price trends over time

## 💾 Your Data

- **All data is stored in your browser** (localStorage)
- Works completely **offline** - no internet needed after download
- Your data stays **private** - never sent to any server
- Data persists between sessions
- **Note**: If you clear your browser data/cache, you'll lose your tracked prices

## ❓ Troubleshooting

**File won't open?**
- Make sure it has the `.html` extension
- Try right-click → "Open with" → Choose your browser

**Data disappeared?**
- Check if you opened the same file (not a new copy)
- Make sure you didn't clear browser data

**Predictions not showing?**
- You need at least 3 price entries per destination
- Make sure prices have different dates

**Want to start fresh?**
- Open browser developer tools (F12)
- Go to "Application" or "Storage" tab
- Clear localStorage for this file
