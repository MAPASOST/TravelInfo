BUDGET VISUALIZATION WEB APP
============================

HOW TO USE:
-----------
1. Double-click "BudgetApp.html" to open in your browser
2. Click the first box to upload your budget Excel file
3. Click the second box to upload your P&L Excel file
4. Click "Generate Analysis" button
5. View all the charts and tables!

IMPORTANT:
----------
- Use BudgetApp.html (not index.html)
- You need internet connection the FIRST time you open it
- After that, it remembers everything and works offline

EXCEL FILE FORMAT:
------------------
Your Excel files should look like this:

| Category   | Jan   | Feb   | Mar   | Apr   | ...
|------------|-------|-------|-------|-------|----
| Salaries   | 50000 | 50000 | 50000 | 50000 | ...
| Marketing  | 10000 | 12000 | 15000 | 8000  | ...
| Operations | 20000 | 22000 | 21000 | 23000 | ...

- First row: Headers (Category + period names)
- First column: Category names
- Numbers only (no $ or commas)

FEATURES:
---------
✓ Bar charts - Budget vs Actual comparison
✓ Line charts - Spending trends over time
✓ Variance table - Detailed analysis
✓ PDF export - Save your report
✓ Works offline - No internet needed after first load

REQUIREMENTS:
-------------
- Any modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection ONLY for first time (to load libraries)
- After that, works completely offline!

TROUBLESHOOTING:
----------------
- Charts not showing? Make sure you uploaded BOTH files
- Excel file error? Check the format matches example above
- PDF not exporting? Try a different browser
