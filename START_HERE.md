# 🎯 START HERE - Download Your App

## Simple Instructions (No Coding!)

### Step 1: Go to This Link
👉 **https://github.com/MAPASOST/TravelInfo/actions**

### Step 2: Wait 5-10 Minutes
The app is being built automatically right now. If you don't see anything yet, wait a few minutes and refresh the page.

### Step 3: Download
1. Click on the **first/top** item in the list (most recent)
2. Scroll to the bottom
3. Look for "Artifacts" section
4. Click **"BudgetVisualization-Windows"** to download

### Step 4: Unzip and Run
1. Find the downloaded ZIP file (probably in your Downloads folder)
2. Right-click → "Extract All"
3. Inside, you'll see **BudgetVisualization.exe**
4. **Double-click it to run!**
