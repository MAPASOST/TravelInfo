====================================
BUDGET VISUALIZATION - PYTHON APP
====================================

SUPER SIMPLE - Just 3 Steps:
-----------------------------

STEP 1: Install Python (if you don't have it)
   - Go to: https://www.python.org/downloads/
   - Click the big yellow "Download Python" button
   - Run the installer
   - ⚠️ CRITICAL: Check the box "Add Python to PATH"
     (It's at the BOTTOM of the first installer screen)
   - Click "Install Now"
   - Wait for it to finish

STEP 2: Run INSTALL.bat (one-time setup)
   - Double-click "INSTALL.bat"
   - It will install 3 libraries (takes 1-2 minutes)
   - Wait for "SUCCESS! Installation complete!"

STEP 3: Run the app
   - Double-click "run.bat"
   - The app window opens!


THAT'S IT!
----------
After the first-time setup, just double-click "run.bat" to open the app.


HOW TO USE THE APP:
-------------------
1. Click "Upload Budget File" and select your budget Excel file
2. Click "Upload P&L File" and select your P&L Excel file
3. Click "Generate Analysis"
4. View the charts in the tabs:
   - Budget vs Actual (bar chart)
   - Trend Analysis (line chart)
   - Variance Table (detailed breakdown)


EXCEL FILE FORMAT:
------------------
Your Excel files should look like this:

| Category   | Jan   | Feb   | Mar   | Apr   | ...
|------------|-------|-------|-------|-------|----
| Salaries   | 50000 | 50000 | 50000 | 50000 | ...
| Marketing  | 10000 | 12000 | 15000 | 8000  | ...
| Operations | 20000 | 22000 | 21000 | 23000 | ...

- First row: Headers (Category + month names)
- First column: Category names
- Numbers only (no $ or commas)
- Both files should have the same categories


WHAT YOU GET:

✓ Line charts showing trends
✓ Detailed variance table with color coding
✓ No internet needed after installation
✓ All your data stays on your computer


TROUBLESHOOTING:
----------------

Problem: "Python is not installed"
Solution: Install Python from https://www.python.org/downloads/
         Make sure to check "Add Python to PATH"!

Problem: App won't start
Solution: Right-click run.bat → "Run as administrator"

Problem: "Error parsing Excel file"
Solution: Make sure your Excel file matches the format above
         First column must be category names
         Other columns must be numbers only
